**GitHub-first 编码 Agent 控制系统。**

SWEAgent 接收签名验证后的 GitHub issue / PR 事件，将运行记录写入 SQLite，根据触发规则选择分析或编码工作流，在 Docker 中运行配置好的 OMP Agent，执行验证，并交付可审查的 GitHub 产物。它适合希望把 AI 编码工作纳入权限、审计、验证和人工 review 边界的团队。
